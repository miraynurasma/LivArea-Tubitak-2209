# 🏙️ LivArea: Veri Güdümlü Şehir Analiz Sistemi

LivArea, Türkiye'nin 81 ilini 5 farklı ana parametre üzerinden analiz eden, interaktif bir **Yaşanabilirlik Karar Destek Sistemidir.**

## 🚀 Proje Vizyonu
Bu çalışma, TÜBİTAK 2209-A Üniversite Öğrencileri Araştırma Projeleri Destekleme Programı kapsamında geliştirilmiştir. Kullanıcıların demografik, ekonomik ve çevresel önceliklerine göre en uygun yaşam alanlarını keşfetmelerini sağlar.

### 📊 Analiz Parametreleri
* 💰 **Konut Maliyeti:** Güncel kira bedelleri analizi.
* 🍃 **Hava Kalitesi:** PM2.5 değerleri üzerinden çevresel sağlık ölçümü.
* 💼 **İstihdam:** İşsizlik oranları üzerinden ekonomik fırsat haritası.
* 🧘 **Sakin Yaşam:** Nüfus yoğunluğu ve demografik huzur endeksi.
* 🚗 **Ulaşım:** Araç sayısı üzerinden trafik ve lojistik kolaylık analizi.

## 🛠️ Teknik Altyapı
* **Frontend/Backend:** Streamlit (Python tabanlı Dashboard)
* **Veri Görselleştirme:** Plotly Express (İnteraktif Mapbox Haritaları)
* **Veri İşleme:** Pandas & NumPy (Normalize edilmiş skorlama algoritmaları)
* **Versiyon Kontrol:** Git & GitHub
